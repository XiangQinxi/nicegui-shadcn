# 浮层与反馈

对话框、抽屉、sheet、气泡卡片、右键菜单、命令面板与 toast。它们都是 `ValueElement`：
`value` 表示「是否打开」，`open()` / `close()` / `toggle()` 可以直接从回调里驱动，
不必依赖触发器。
